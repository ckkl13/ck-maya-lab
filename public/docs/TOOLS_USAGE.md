# CK MAYA LAB 三套工具使用手册

> 适用工具：CK Rig Box 1.9、CK Tool 1.2、Scripts Box 1.0  
> 文档依据：`E:\个人博客\tools` 中的当前 UI 与功能源码  
> 更新日期：2026-07-25

## 1. 使用前说明

- 三套工具都应在 Autodesk Maya 内运行。网页只用于查看界面、学习操作和预览状态，不会执行 Python、MEL 或修改 Maya 场景。
- 执行会修改场景的命令前，建议保存文件；大量处理前建议先复制测试场景。
- 如果按钮没有结果，先检查 Maya 当前选择、对象类型、名称和层级是否满足该功能的输入条件。
- CK Rig Box 的网页演示会模拟控制器、层级与约束结果；CK Tool 和 Scripts Box 的网页演示只还原界面交互。

## 2. CK Rig Box

### 2.1 准备选择

1. 在 Maya 中按根到末端建立或整理关节/Transform 层级。
2. 选中要处理的根节点；需要处理多条链时，按希望的顺序选择多个根节点。
3. 打开“FK工具”，先设定层级模式、排除字符和控制器形状，再设定约束与其他选项。
4. 点击“创建并约束”。如果只需要辅助节点，则使用“创建定位器”或“创建次级”。

### 2.2 基础设置

| 控件 | 用法 | 结果 |
| --- | --- | --- |
| 层级模式：zero层级 | 默认完整结构 | 建立完整的 Zero/Driven/Connect/Offset/Ctrl/Output 组织层级 |
| 层级模式：zero简化 | 需要更短层级时使用 | 建立简化的 Zero/Ctrl/Output 结构 |
| 层级模式：GP层级 | 需要 Group/Parent 逻辑时使用 | 使用 GP 风格的分组结构组织控制器 |
| 层级模式：ADV层级 | 接入 Advanced Skeleton 风格时使用 | 使用 ADV 命名与层级逻辑 |
| 排除字符 | 输入要从源对象名移除的片段 | 支持英文或中文逗号，例如 `jnt_, bind_` |
| 控制器形状 | 选择 Cube、Circle 或 Square | 所有新建主控制器使用所选形状 |

### 2.3 约束类型

- **Parent**：把位移和旋转一起约束到控制器；默认开启。
- **Point**：只约束位移。若已使用 Parent，通常不需要再打开 Point。
- **Orient**：只约束旋转。需要分离位移/旋转控制时可与 Point 组合。
- **Scale**：约束缩放；默认开启。角色缩放链路不需要时可以关闭。

### 2.4 选项

- **FK层级模式**：把相邻控制器按源链顺序组成 FK 父子层级。关闭后，每个控制器保持独立组织。
- **次级控制器**：为主控制器增加一层可独立调整的次级控制器。
- **次级归属 / 归属 Output**：让次级控制器相关子节点归入 Output，适合把输出层与主 Ctrl 分开。
- **次级归属 / 归属 Ctrl**：让相关子节点归入 Ctrl，适合更直接的控制器层级。
- **排除末尾**：不为链条最后一个对象建立主控制器，常用于只作为末端标记的 joint。
- **重建之前的约束**：仅用于“创建次级”。工具在插入次级控制器后重新建立原控制器已有约束。
- **FK复制模式**：复制一条 FK 关节链并围绕复制链建立控制器，而不是直接使用原链。

### 2.5 三个执行按钮

#### 创建定位器

1. 选择一个或多个场景对象。
2. 点击“创建定位器”。
3. 工具在选择对象下创建并对齐 Locator，作为后续定位或挂接节点。

#### 创建次级

1. 选择已有的 NURBS 控制器曲线。
2. 选择“次级归属”。
3. 根据需要开启“重建之前的约束”。
4. 点击“创建次级”。工具为选择曲线插入次级控制层，并按选项恢复约束。

#### 创建并约束

1. 选择层级根节点。
2. 完成基础、约束和选项设置。
3. 点击“创建并约束”。
4. 检查 Outliner 中的控制器层级、源对象约束和末端是否符合预期。

### 2.6 常用方案

- **标准 FK 链**：zero层级 + Parent + Scale + FK层级模式。
- **位移旋转拆分**：关闭 Parent，打开 Point + Orient；Scale 按项目规范决定。
- **更轻的控制器层级**：zero简化 + FK层级模式。
- **末端不建控制器**：开启“排除末尾”。
- **保留原链并生成驱动链**：开启“FK复制模式”。
- **已有控制器增加细调层**：选择控制器后使用“创建次级”，必要时开启“重建之前的约束”。

### 2.7 结果检查

- 控制器名称应以移除前缀后的源对象名为主体。
- FK 模式下，上一级控制器应能带动下一级控制器组。
- 开启的约束类型应出现在源对象上；没有选择的约束类型不应被创建。
- 开启次级控制器时，主控制与次级控制应是两个可辨认的曲线层。
- 开启排除末尾时，最后一个源对象仍保留，但没有对应主控制器。

## 3. CK Tool

### 3.1 固定控制区

- **曲线大小 / 变大 / 变小**：先选择 NURBS 曲线控制器，设置步长后点击按钮，工具缩放曲线 CV，不改变 Transform 缩放值。
- **使用形状局部中心缩放**：开启后，每个 Shape 围绕自己的局部中心缩放；关闭时按普通选择中心处理。
- **曲线粗细 / 应用粗细**：选择曲线，输入线宽后应用到 Shape 显示属性。
- **位移归0 / 旋转归0 / 缩放归1**：把选择对象对应通道恢复为 0、0、1；锁定或不可写通道会被跳过。

### 3.2 控制器颜色

1. 选择一个或多个控制器。
2. 点击颜色预览选择自定义 RGB，或点击预设色块。
3. 点击“应用颜色”写入 Shape 的覆盖颜色。
4. “重置颜色”关闭/恢复覆盖；“随机颜色”为选择对象分配不同颜色；“渐变颜色”打开渐变工具并按对象顺序插值。

### 3.3 创建关节与控制器

#### 命名与数量

- **自定义组名称 / 启用自定义组**：指定新建内容所属的顶层组。
- **名称**：对象名称主体。
- **侧面**：使用 `l`、`r`、`m` 等侧别字段。
- **控制器大小**：新建控制器形状尺寸。
- **数量**：一次创建的对象组数。
- **控制器类型**：选择 Sphere、Cube、Circle、Arrow、Gear、Diamond 等形状。
- **编号位数**：控制末尾序号补零长度，例如 2 位得到 `01`。

#### 创建选项

- **创建关节**：生成 joint。
- **创建控制器**：生成 NURBS 控制器及配套组。
- **创建子控制器**：在主控制器下增加细调控制器。
- **识别物体名称**：从当前选择对象提取名称和侧别，而不是完全使用手输名称。
- **忽略后缀**：识别名称时不把原末尾序号/后缀重复带入。
- **使用层级组逻辑**：根据选择对象原层级建立新控制器组之间的父子关系。

设置完成后点击“创建”。若需要匹配现有对象，应先按正确顺序选择目标，并检查生成后的父子层级。

#### 曲线辅助命令

- **镜像曲线形状**：按对称轴把源控制器 Shape 镜像到目标侧。
- **替换曲线形状**：用源曲线 Shape 替换目标控制器 Shape，保留目标 Transform。
- **添加形状节点**：把选择曲线的 Shape 重新归属到目标 Transform，可制作多形状控制器。
- **曲线Shape重命名**：按 Transform 名自动规范 Shape 节点名称。
- **切换显示在前面**：切换控制器 `alwaysDrawOnTop`，减少被模型遮挡。
- **次级控制器**：为选择控制器建立次级控制层。
- 源码还提供曲线合并、曲线拆分和变换匹配能力；使用时按“源对象在前、目标对象在后”的选择顺序执行，并在 Outliner 检查 Shape 归属。

### 3.4 分组与前缀设置

1. 选择需要增加组层级的对象。
2. 输入“自定义前缀”，或选择 zero、driven、connect、offset、space 等预设前缀。
3. 设置选项：
   - **去除前缀**：先清理对象已有前缀再生成组名。
   - **使用现有后缀**：保留原名称序号。
   - **冻结缩放**：建组前处理选择对象缩放。
   - **创建 Locator**：在组织结构中增加定位节点。
4. 点击“创建组”。
5. “添加控制器层级”用于为已有控制器补充标准层级；“基础层级”用于打开/建立基础控制系统。
6. “创建父物体/创建子物体”类操作要先确认当前选择，父物体会插入对象上方，子物体会建立在对象下方。

### 3.5 创建 Tag 并选择

- **添加Tag**：输入 Tag 名，给选择对象增加布尔标记属性。
- **选择有tag的物体**：在场景中选择具有该属性的对象。
- **删除 Tag**：从选择对象移除指定 Tag 属性。
- **识别选中物体的 Tag**：读取选择对象已有 Tag 并写入历史记录。
- **历史 Tag 记录**：快速回填曾使用的 Tag 名。
- **清空历史 Tag 记录**：清除工具保存的 Tag 名历史，不删除场景对象上的属性。

### 3.6 骨骼 Tag

- **骨骼绘制标签**：切换/建立 joint 的可视标签，便于在视口识别骨骼。
- **通用骨骼Tag**：给关节写入工具约定的通用标记，供后续选择或识别流程使用。

### 3.7 推荐工作流

- **已有控制器改造**：调整大小 → 设线宽 → 设颜色 → 规范 Shape 名 → 切换显示在前面。
- **从关节创建控制器**：选关节 → 开启名称识别和层级逻辑 → 选控制器类型 → 创建 → 检查约束/层级。
- **批量组织控制器**：选控制器 → 选择预设前缀 → 创建组 → 添加控制器层级。
- **用 Tag 管理集合**：输入稳定的 Tag 名 → 批量添加 → 用“选择有tag的物体”召回。

## 4. Scripts Box

### 4.1 界面与分组

- 左侧是脚本分组，括号内为脚本数量；点击分组在右侧显示内容。
- 点击左侧“+”创建分组。
- 右键分组可重命名、删除和设置分组颜色。
- 拖动分组按钮调整顺序；也可把脚本移动到其他分组。
- 删除的脚本或分组先进入回收站，未永久删除前可恢复。

### 4.2 新建、选择与运行脚本

1. 进入目标分组，点击顶部“+”。
2. 填写脚本名称，选择 Python 或 MEL，填写可选提示信息和代码。
3. 保存后，脚本按钮出现在当前分组。
4. 单击脚本按钮运行；网站演示只显示选中状态，不执行代码。
5. 中键或工具支持的编辑入口可打开内置编辑器。

右键脚本按钮可使用：编辑、删除、置顶/取消置顶、编辑提示信息、设置按钮颜色、移动到分组和打开文件夹。置顶脚本会排在普通脚本之前。

### 4.3 搜索与布局

- 在顶部搜索框输入名称关键词，结果会跨分组实时过滤，并显示类型和原分组。
- 点击清除按钮或清空输入恢复当前分组。
- 刷新按钮重新读取配置与脚本文件。
- 设置中可切换单列/双列按钮布局，并调整界面比例。

### 4.4 拖放导入

1. 在文件管理器选择 `.py` 或 `.mel` 文件，可多选。
2. 拖到 Scripts Box 窗口。
3. 确认目标分组与同名文件处理结果。
4. 导入后刷新并检查脚本名称、类型和提示信息。

### 4.5 内置编辑器

- 可编辑脚本名称、Python/MEL 类型、提示信息和代码正文。
- 查找栏支持上一个、下一个、区分大小写和匹配计数。
- 保存前脚本名称和内容不能为空。
- 编辑器内的“运行”会在 Maya 中执行当前代码；运行外部脚本前应先审查来源和内容。

### 4.6 回收站

- 点击左下角回收站查看已删除脚本和分组。
- 单项“恢复”会放回原分组；原分组不存在时按工具提示处理。
- “全部恢复”恢复当前所有项目。
- 单项“删除”或“清空回收站”属于永久删除，确认前应先检查是否需要备份。

### 4.7 配置导出

打开“设置 → 导出配置”，可选择：

- **仅导出配置**：导出 `config.json`，包括分组顺序/颜色、按钮布局/颜色、置顶列表、回收站、提示信息和界面比例。
- **仅导出脚本文件**：导出 `tools` 目录并保留分组结构。
- **导出配置和脚本文件**：用于完整备份或团队共享。

导出目录格式为 `scripts_box配置_YYYYMMDD_HH-MM`。

### 4.8 配置导入

打开“设置 → 导入配置”，选择包含 `config.json` 和/或 `tools` 目录的文件夹：

- **添加配置**：保留现有配置，追加新项，同项替换。
- **添加脚本文件**：保留现有脚本，追加新脚本，同名替换。
- **添加配置和脚本**：同时合并两部分。
- **替换全部**：完全替换现有配置和脚本，风险最高。

导入前工具会备份当前状态到 `data/backup/YYYYMMDD_HH-MM`。建议先使用添加模式验证，再考虑替换全部。

### 4.9 工具架管理

- 查看当前 Maya 版本与工具架目录。
- “保存”把 Maya 工具架保存到本地。
- “加载”把已保存工具架载入 Maya。
- 可刷新列表和删除不再需要的保存项，用于跨版本或项目共享工具架。

### 4.10 折叠图标

- 点击主窗口最小化按钮，把窗口收纳为 Maya 内的悬浮图标。
- 单击图标临时展开；点击其他位置或再次单击会收回。
- 双击图标完整恢复主窗口。
- 拖动图标改变位置；右键选择“关闭”退出。
- 设置中可选择静态图片或 GIF 作为图标，也可重置默认图标。

### 4.11 安全建议

- 只运行来源可信、已经阅读过的 Python/MEL。
- 团队共享前同时导出配置和脚本，并保留版本号或日期。
- 使用“替换全部”和“清空回收站”前，再做一次外部备份。
- 导入目录中的脚本文件夹必须名为 `tools`，配置文件必须名为 `config.json`。

## 5. 常见问题

### 按钮可点但 Maya 没有结果

检查当前是否在网页演示中；网页永远不会连接或控制本机 Maya。请在 Maya 内安装并启动工具包。

### CK Rig Box 创建数量不对

检查是否开启了“排除末尾”、是否选择了正确根节点，以及源层级中是否混入不应递归处理的对象。

### CK Tool 只改到部分控制器

检查选择的是 Transform 还是 Shape、对象通道是否锁定，以及曲线是否为 NURBS Curve。

### Scripts Box 导入后看不到脚本

检查文件扩展名是否为 `.py`/`.mel`、目标文件夹是否名为 `tools`，然后刷新并确认当前分组或清除搜索条件。
