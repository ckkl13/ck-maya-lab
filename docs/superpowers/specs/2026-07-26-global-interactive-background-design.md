# 全站交互背景与区域融合切换设计

## 目标

为 CK Maya Lab 增加贯穿首页、工具展示、交互台、使用说明和下载区的统一交互背景，并强化向下滚动时的区域融合感。效果采用中等强度：足够明确，但不遮挡 Maya 工具 UI、不抢占交互，也不依赖持续高负载动画。

## 成功标准

- 桌面端鼠标在页面任意区域移动时，背景光场、网格和粒子产生平滑响应。
- 从一个主要区域滚动到下一区域时，背景、内容明暗和扫描线形成连续过渡。
- 工具窗口、按钮、输入框和链接保持原有点击、拖动与键盘操作。
- 手机和平板不跟随触控，仅保留轻量滚动过渡。
- `prefers-reduced-motion: reduce` 下停止视差、扫描与内容位移。
- 页面没有新增横向溢出，动画不通过 React state 高频刷新。
- 现有三个工具演示和使用说明内容不改变。

## 视觉方案

### 全局背景层

在应用内容下方放置一个固定的 `GlobalInteractiveBackground`：

1. 深色基础底板，维持当前 Maya 展览气质。
2. 两层不同尺度的细网格，鼠标移动时以不同幅度产生视差。
3. 一个青色主光场和一个低饱和冷灰辅助光场。
4. 少量固定粒子节点与短连接线；靠近鼠标时只改变位移和亮度，不运行持续随机漂浮。
5. 一条用于区域过渡的水平扫描线，默认隐藏。

背景层设置 `pointer-events: none` 和 `aria-hidden="true"`。主要区域使用适度透明的深色表面，让背景在留白区域可见；Maya 工具窗口、导航和文字承载面保持不透明。

### 指针响应

指针坐标归一化后写入全局 CSS 自定义属性：

- 光场直接跟随页面内指针位置，并使用缓动追赶。
- 远、中、近三组位移保持不同幅度，制造深度。
- 粒子仅做小范围 transform 和 opacity 变化。
- 指针离开页面后平滑回到中心状态。

只在 `(pointer: fine)` 且未启用减少动态效果时启用。频繁更新使用一个动画帧或 GSAP `quickTo()`，不调用 React `setState`。

## 区域融合切换

主要场景为：

1. Hero
2. 工具展示
3. 工具交互台
4. 使用说明
5. 下载区域

每个场景增加统一的 `data-scene` 标记，由 `SceneTransitions` 使用 ScrollTrigger 协调：

- 场景进入视口时，从 `y: 36–40px`、轻微降亮状态恢复到正常位置和亮度。
- 上一场景在离开中心区域时轻微缩小到约 `0.985`，并降低背景层亮度；内容不完全消失。
- 全局背景的光场位置、网格纵向偏移和粒子透明度随滚动连续变化。
- 场景交界处触发一次青色扫描线，由上至下快速穿过可视区域。
- 页面侧边显示低调的场景编号和整体滚动进度，帮助识别当前章节。

不启用滚动吸附、整页强制停留或长时间 pin，保证长篇说明和工具 UI 能自然滚动。

## 组件与职责

### `GlobalInteractiveBackground`

- 渲染固定背景、网格、粒子和扫描线。
- 监听细粒度指针输入并更新 CSS 属性。
- 不读取或修改工具演示状态。
- 卸载时清理监听器、动画和帧请求。

### `SceneTransitions`

- 发现带 `data-scene` 的一级场景。
- 为每个场景建立有限数量的 ScrollTrigger。
- 控制进入、离开、背景主题变化和当前章节编号。
- 在组件卸载和媒体条件变化时完整清理。

### 现有场景组件

- 仅添加稳定的场景标记和必要的样式类。
- 保留当前组件结构、内部动画与交互逻辑。

## 响应式与可访问性

- 桌面细指针：完整光场、网格视差、粒子响应和滚动融合。
- 触屏或窄屏：取消指针追踪和场景缩放，保留背景渐变、轻量淡入和滚动进度。
- 减少动态效果：所有位移固定为零，隐藏扫描线与动态进度，仅保留静态深色背景。
- 背景没有语义内容，不进入可访问性树。
- 文字与工具 UI 的对比度不依赖背景动画。

## 性能约束

- 高频属性仅使用 transform、opacity 和 CSS 自定义属性。
- 不在指针事件中读取多次布局或创建新 tween。
- 粒子数量保持在小规模，不使用 Canvas 永久渲染循环。
- ScrollTrigger 数量与五个主要场景线性对应，不为内部每个控件创建触发器。
- `will-change` 只用于实际动画的背景层和扫描线。
- 所有 GSAP 行为通过 `useGSAP` 作用域管理并自动清理。

## 验证

- 自动测试检查全局背景组件、五个场景标记、减少动态效果和无 React 高频状态更新。
- 运行 `npm test`、`npm run lint`、`npm run build` 和依赖审计。
- 桌面端验证指针响应、五个区域过渡、工具 UI 点击和控制台。
- `390 × 844` 验证无横向溢出、触控降级和说明区可读性。
- 开启 `prefers-reduced-motion` 验证动态被正确停用。

## 非目标

- 不增加滚动吸附。
- 不引入 Canvas/WebGL 粒子引擎或新的动画依赖。
- 不重构三个 Maya 工具演示。
- 不调整工具文档内容、下载文件或兼容信息。
