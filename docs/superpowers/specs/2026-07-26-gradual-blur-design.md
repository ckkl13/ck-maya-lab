# React Bits GradualBlur 整合设计

## 目标

在 CK Maya Lab 页面底部加入固定的渐进模糊层，使下方内容在滚动进入可视区域时逐层变清晰，并与现有全站交互背景、扫描线和电影式场景过渡融合。

## 放置与视觉参数

- 位置：页面底部固定，`target="page"`、`position="bottom"`。
- 桌面高度：约 `7rem`。
- 桌面层数：6 层。
- 强度：低到中等，基础值约 `1.8`。
- 曲线：`bezier`。
- 模糊增长：指数增长，使最底部模糊更明确而上缘自然消失。
- 透明度：约 `0.86`，避免遮蔽工具 UI。
- 层级：位于页面内容上方、固定导航和章节指示下方。
- 交互：全部使用 `pointer-events: none`，不影响工具按钮、输入框、链接或滚动。

## 组件实现

新增 TypeScript 版 `GradualBlur` 和独立 CSS：

- 仅实现当前站点需要的 top/bottom/page/parent、曲线、指数强度和响应式能力。
- 保留清晰的 props 类型，避免复制附件中未使用的预设和运行时样式注入。
- 使用 `useMemo` 计算有限数量的模糊层。
- 不安装附件声明但源码未使用的 `mathjs`。
- 组件作为纯视觉层在 `App` 中只渲染一次。

## 响应式与降级

- 桌面：6 层、约 `7rem` 高度。
- 触屏或窄屏：4 层、约 `4.5rem` 高度、降低强度。
- `prefers-reduced-motion` 不需要关闭模糊，因为组件不持续运动；禁用额外淡入动画。
- 浏览器不支持 `backdrop-filter` 时，使用透明深色渐变作为降级，不模拟昂贵滤镜。

## 性能约束

- 不创建滚动监听器、持续动画循环或 React 高频状态更新。
- 模糊层固定为小规模，桌面最多 6 层。
- 不对整页内容本身应用 blur，只让固定遮罩层使用 `backdrop-filter`。
- 不添加新运行时依赖。

## 验证标准

- 页面底部能看到由清晰到模糊的平滑过渡。
- 鼠标和触控仍可操作模糊层后方的页面控件。
- 现有场景编号、扫描线和固定导航保持清晰并位于模糊层之上。
- 390px 宽度无横向溢出，使用 4 层低强度配置。
- 不支持 `backdrop-filter` 时仍有自然的深色渐变。
- 测试、lint、生产构建和依赖审计通过。

## 非目标

- 不在每个场景交界处重复创建 GradualBlur。
- 不在顶部导航下方增加第二个模糊层。
- 不改变现有 Maya 工具 UI、使用说明或下载内容。
