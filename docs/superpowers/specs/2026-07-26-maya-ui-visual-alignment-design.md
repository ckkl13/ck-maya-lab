# CK Maya Lab 真实 Maya 界面视觉校准设计

## 目标

在保留 CK Maya Lab 数字艺术展览气质的前提下，让 CK Tool、Scripts Box 的交互台与 CK Rig Box 属于同一套网页舞台，同时继续忠实呈现各自在 Maya 内的真实窗口结构。

## 已确认边界

- CK Tool、Scripts Box 只展示 UI 交互，不执行 Maya、Python 或 MEL。
- CK Rig Box 保留当前网页模拟能力。
- 三个交互台共享统一的网页舞台、边框、标题区、阴影和反馈语言。
- 每个工具内部仍以实际 Maya 截图为视觉依据，不把三个工具强行改成完全相同的控件布局。
- 全站兼容信息统一为 `Maya 2022+` 和 `Windows.Mac`。

## 交互台设计

### 统一网页外壳

- 延续 CK Rig Box 当前的深色展示舞台和紧凑工具栏。
- 三个工具使用一致的边框明度、圆角、阴影、间距和悬停反馈。
- Maya 窗口区域与网站背景保持清晰层级，不增加霓虹边框或夸张发光。
- 按钮、输入框和滚动条的状态变化遵循同一套速度与对比度。

### CK Tool

- 移除左侧工具简介中的 CK Tool 截图，只保留版本、简介、兼容信息和获取入口。
- 工具窗口继续采用实际 Maya 中的窄长比例。
- CK Tool 窗口内部、曲线大小控件上方当前显示圆形球的位置，替换为现成 `siri.gif`；侧栏、首页和作品区不使用该 GIF。
- 保留曲线大小、曲线粗细、通道重置和五个折叠区域。
- 美化范围仅限间距、文字层级、边框、按钮状态与折叠动画。

### Scripts Box

- 保留真实 Maya 布局：左侧脚本分组、顶部搜索与操作按钮、右侧双列脚本列表。
- 分组数量、脚本类型图标、选中状态和滚动区域继续可交互展示。
- 调整窗口表面、分隔线、滚动条、按钮高度和字体层级，使其与 CK Rig Box 舞台协调。
- 不改变真实功能分区，不增加虚假执行结果。

## 说明区域

- 移除白色主题，统一改为深炭黑背景。
- 章节面板使用深灰表面和低对比度分隔线。
- 冷青色只用于当前工具、章节进度、连接线和关键结果。
- 正文保持足够对比度，但避免大面积纯白背景造成眩光。
- 原有工具切换、章节切换、步骤动画和 Markdown 下载入口保留。

## 首页与作品区

- 首屏三层工具画面替换为用户提供的真实 Maya 截图。
- CK Rig Box 作为主画面；CK Tool 和 Scripts Box 作为前后景辅助画面。
- 作品区每件工具直接使用对应真实截图。
- 图片容器按素材宽高比调整：
  - CK Rig Box：窄窗口，避免被横向拉伸。
  - CK Tool：长窗口，完整显示折叠区域。
  - Scripts Box：宽窗口，突出左右分栏。
- 保留现有 GSAP 进入、视差和作品切换动画，但限制缩放与裁切，确保控件可辨认。

## 兼容信息

以下位置统一显示：

- `Maya 2022+`
- `Windows.Mac`

覆盖工具数据、交互台侧栏、作品区、下载区、首页概览和使用说明中属于全站兼容性的展示文案。源码引用或历史说明中的版本事实不做无关改写。

## 响应式与可访问性

- 桌面端保持真实截图完整可读。
- 移动端优先完整窗口轮廓，允许内部文字缩小，不横向撑开页面。
- `390px` 视口无页面级横向滚动。
- `prefers-reduced-motion` 下关闭视差和长时间轴。
- 所有工具切换、折叠区域、搜索和章节按钮保留键盘名称与焦点状态。

## 验收标准

- 首页和作品区只使用三张用户提供的真实 Maya 截图。
- CK Tool 交互台侧栏不显示工具截图。
- CK Tool 交互窗口中原圆形球的位置显示 `siri.gif`，其他区域不显示该 GIF。
- CK Tool、Scripts Box 与 CK Rig Box 共享一致网页舞台语言，同时保持各自 Maya 布局。
- 说明区域全程为深色主题。
- 全站兼容信息显示为 `Maya 2022+`、`Windows.Mac`。
- CK Tool、Scripts Box 不出现功能执行或伪造结果。
- 桌面和 `390px` 手机端无关键裁切或页面横向溢出。
- 测试、lint、类型检查、生产构建与依赖审计通过。
